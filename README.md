## رفع التحديث إلى Vercel (Upload)
1) افتح لوحة Vercel → مشروعك → Deployments → New Deployment → **Upload**.
2) اسحب هذا المجلد (أو فكّ ضغط الـ ZIP واسحب الملفات) لبدء نشر نسخة جديدة.
3) بعد الانتهاء، جرّب الرابط واضغط تحديث قوي (Ctrl+F5).

> لو تستخدم GitHub بدل الرفع اليدوي: انسخ هذه الملفات فوق ملفاتك ثم:
```
git add .
git commit -m "Update canonical, og:url, robots, sitemap to https://weighted-calculator-p9fdepuxt-yousif-ahmeds-projects-6ee2ff57.vercel.app/"
git push
```
Vercel سيعيد النشر تلقائيًا.
